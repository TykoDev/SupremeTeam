# Supreme Team installer item list: the one list install.sh and install.ps1 both
# read. scripts/test_install.py ties it to skills/ and to both installers, so a
# skill added to the tree cannot be left out of an install without a test failing.
#
# One record per line, fields separated by spaces. Names are single path
# components under skills/.
#
#   core <name>            copied on every install
#   seed <name>            a core file created when it is missing and never
#                          replaced, because the copy on disk belongs to the user
#   supersedes <seed> <file>...
#                          copies of <seed> that earlier releases shipped, kept in
#                          scripts/superseded/. A seed that is byte for byte one of
#                          them was never edited, so it is replaced like any file
#                          the installer owns; any other copy stays the user's
#   team <team> <name>...  copied when the team is selected (default: all teams)
#   legacy <dir> <name>... a directory an older layout created; it is recognised
#                          only while it holds nothing but these entries, and is
#                          then moved to the backup folder, never deleted
